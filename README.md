## ภาพรวม
- โปรเจกต์นี้ใช้ ESP32 ธรรมดาตัวเดียว (ไม่ต้องมี PSRAM) ทำเครื่องเล่นขนาดเล็กที่มีเมนูให้เลือกสองอย่าง คือ Bad Apple แบบภาพและเสียง กับเกมยิงมุมมองบุคคลที่หนึ่งแนว DOOM บนจอ OLED 128x64
- • เมนูหลัก: เลือกด้วยปุ่ม มีไอคอนแอปเปิลและหัวกะโหลก แผงที่เลือกอยู่กลับสีและมีลูกศรกระพริบ
- • Bad Apple: วิดีโอ 3 นาทีครึ่ง 15 เฟรมต่อวินาที เก็บบน SD card เล่นพร้อมเสียงผ่านแอมป์ MAX98357A
- • เกมแนว DOOM: เกม raycaster เขียนเอง มีผนัง ศัตรู 5 ตัว การยิง เลือดผู้เล่น เสียงเอฟเฟกต์ และเพลงประกอบที่เริ่มเมื่อเริ่มเกมและหยุดเมื่อเกมจบ
- เกมในโปรเจกต์นี้ไม่ใช่ DOOM ต้นฉบับ เพราะ DOOM ตัวจริงต้องการ PSRAM (ESP32 รุ่น WROVER หรือ S3) บอร์ดแบบ WROOM-32 ทั่วไปรันไม่ได้ จึงเขียนเกมแนวเดียวกันขึ้นเองด้วยหลักการ raycasting ที่ใช้ RAM น้อยมาก
## อุปกรณ์ที่ต้องใช้
- ทั้งหมดไม่ต้องบัดกรี ถ้าซื้อโมดูลที่มีขา header ติดมาแล้ว ราคาและสต็อกให้เช็กกับร้านเอง
- บอร์ด ESP32 ตัวที่ผมใช้เป็น (ESP32-WROOM-32 / ชิป D0WD-V3) x1
- จอ OLED 0.94" 128x64 แบบ I2C 4 ขา x1
- mh-sd card module  x1
- SD card 4GB x1
- โมดูลแอมป์ MAX98357A (I2S) x1
- ลำโพง 8 Ω 2-3 W ขนาด 40-57 mm x1
- ปุ่มกดแบบ tactile 4 ขา x5
- Breadboard และสายจัมเปอร์ผู้-ผู้ x1 ชุด (มีเยอะกว่านี้จะดีมาก)
- สาย USB แบบมีสายข้อมูล x1
- ไขควงปากแบนจิ๋ว
## การต่อสาย
## จอ OLED 
- GND > GND
- VCC > 3v3 หรือ 5v
- SCL > G22
- SDA > G21
## โมดูล SD card
- GND > GND
- VCC > 5V (ขา VIN) หรือตามป้ายบนโมดูล
- SCK > G18
- MISO > G19
- MOSI > G23
- CS > G5
## แอมป์ MAX98357A
- Vin > 5V (ขา VIN) ถ้า ESP32 รีเซ็ตให้ใช้ 3V3 แทน
- GND > GND
- BCLK > G26
- LRC > G25 
- DIN > G27
## ปุ่ม
- ปุ่มเดินหน้า > G13 และ GND
- ปุ่มถอยหลัง > G14 และ GND
- ปุ่มเลี้ยวซ้าย > G16 และ GND
- ปุ่มเลี้ยวขวา > G17 และ GND
- ปุ่มยิง > G32 และ GND
## ตั้งค่า 1. Arduino IDE 
- 1. ชุดบอร์ด ESP32: เปิด Tools → Board → Boards Manager ค้นหา esp32 แล้วติดตั้ง "esp32 by Espressif Systems"
- 2. เลือกบอร์ดและพอร์ต: Tools → Board → ESP32 Dev Module แล้วเลือกพอร์ต COM ที่ขึ้นหลังเสียบสาย USB
- 3. ไลบรารีจอ: Tools → Manage Libraries ค้นหา U8g2 (ผู้เขียน olikraus) แล้วติดตั้ง ส่วน SD, SPI และ I2S มากับชุดบอร์ดอยู่แล้ว
- 4. Python 3 กับ numpy: ติดตั้ง Python แล้วเปิด PowerShell พิมพ์ python -m pip install numpy ตอนติดตั้ง Python ต้องติ๊ก "Add python.exe to PATH"
- 5. ffmpeg: เปิด PowerShell พิมพ์ winget install ffmpeg แล้วปิดและเปิด PowerShell ใหม่ เช็กด้วย ffmpeg -version
- คำสั่งทั้งหมดที่มี python หรือ ffmpeg ต้องพิมพ์ใน PowerShell ไม่ใช่ในหน้าต่าง Python ที่มีเครื่องหมาย >>>
## เตรียมไฟล์ Bad Apple
-วิดีโอต้องถูกแปลงเป็นภาพขาวดำ 128x64 และเสียง 15,000 Hz แล้วรวมเป็นไฟล์เดียวชื่อ bad.dat เฟรมละ 1,024 ไบต์ (ภาพ) ตามด้วย 1,000 ไบต์ (เสียง) ที่ 15 เฟรมต่อวินาที ESP32 จึงอ่านทีละเฟรมและให้เสียงเป็นตัวกำหนดจังหวะ ไฟล์วิดีโอต้องหามาเองและใช้อย่างถูกต้องตามสิทธิ์
1. เตรียมโฟลเดอร์ ใน PowerShell
- ตามไฟล์ที่แนบให้ที่ชื่อ เตรียมโฟลเดอร์ ใน PowerShell
- ลากไฟล์วิดีโอมาวางและเปลี่ยนชื่อเป็น badapple.mp4 (ชื่อสั้น ไม่มีช่องว่างหรืออักษรพิเศษ) แล้วเช็กชื่อจริงด้วย dir เพราะ Windows ซ่อนนามสกุลไฟล์ ชื่อที่พลาดบ่อยคือ badapple.mp4.mp4
2. สร้างสคริปต์แปลงภาพ พิมพ์ notepad convert.py กด Yes วางโค้ดนี้แล้ว Ctrl+S (การสร้างไฟล์ด้วยคำสั่งนี้ทำให้ได้นามสกุล .py ที่ถูกต้อง)
- ตามไฟล์ที่แนบให้ที่ชื่อ  สร้างสคริปต์แปลงภาพ
3. แปลงภาพและเสียง ใน PowerShell
- ตามไฟล์ที่แนบให้ที่ชื่อ   แปลงภาพและเสียง
4. รวมภาพกับเสียง พิมพ์ notepad mux.py วางโค้ดนี้ แล้วรัน python mux.py
- ตามไฟล์ที่แนบให้ที่ชื่อ   รวมภาพกับเสียง
5. คัดลอกลง SD card ใส่การ์ดในเครื่องอ่านการ์ดของคอม ฟอร์แมตเป็น FAT32 แล้ววาง bad.dat ไว้ที่รากของการ์ด (ไม่ต้องใส่โฟลเดอร์) แล้วเสียบกลับเข้าโมดูล SD
6. (เลือกทำ) เพลงประกอบเกม ถ้ามีไฟล์เพลงที่คุณมีสิทธิ์ใช้ แปลงด้วยคำสั่งนี้ แล้ววาง doom.raw ไว้ที่รากของการ์ดเช่นกัน เกมจะเล่นไฟล์นี้วนซ้ำ ถ้าไม่มีไฟล์ เกมใช้เพลงเมทัลที่แต่งไว้ในโค้ดแทน
- ตามไฟล์ที่แนบให้ที่ชื่อ   เพลงประกอบเกม
